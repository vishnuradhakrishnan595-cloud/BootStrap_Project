# 🏎️ F1-Zone — Bootstrap Project

A modern and responsive **Formula 1 Racing website** built using **HTML, CSS, JavaScript, and Bootstrap**.

This project was created as a frontend web development project to practice responsive layouts, navigation, racing-themed UI components, images, and interactive elements.
